# STM32 Temperature Controlled Fan

## Description
This project uses an STM32 Nucleo-L476RG to control a fan based on temperature using a DHT11 sensor.

## Features
- Fan turns ON at 75°F
- Fan turns OFF at 72°F
- Button toggles override mode (forces fan OFF)
- Buzzer activates at 80°F
- LCD displays temperature and fan status

## Components
- STM32 Nucleo-L476RG
- DHT11 Sensor
- I2C LCD
- Fan with transistor
- Push button
- Buzzer
